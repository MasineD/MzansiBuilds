# Requirements
This contains all the requirements for completing this project. It includes the client's specifications and technical requirements to develop or run the program.

## Client specifications
The client has asked for a platform that helps developers to build publicly and keep up with what other developers are building. Extra specifications include the following:
        
        1. A developer is able to create and manage own account in order to use the platform.
        2. Can create a new entry for a project he/she is working on including stage and support required.
        3. Can see a live feed of what other developers are working on and can comment / raise a hand for collaboration request.
        4. Continuously, a developer can update their progress for the project with milestones achieved
        5. When a developer has completed the project, they are added into a Celebration Wall amongst other developers who have built in public.

## Technical requirements
In order for the application to run smoothly, the following requirements must be met:

        1. A user must be able to update their project details
        2. A user must be notified when another developer is asking for collaboration
        3. Users must first be authenticated before accessing other pages like the dashboard,overview,projects and celebration wall.
        4. Additionally, the User Interface must adjust to changes in viewport width and height
